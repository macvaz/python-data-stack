| Layer                       | Component                                   | Role                                                                                                       |
| --------------------------- | ------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| **Container Orchestration**           | Kubernetes                                  | Manages all pods, services, scaling, and networking.                                                       |
| **Distributed Compute**     | Ray Cluster                                 | Handles distributed task scheduling, actor management, and parallel execution. |
| **Data Processing / ETL**   | Daft                                        | Provides DataFrame and SQL API for transformations, runs on top of Ray for distributed execution.          |
